# Українські версії правових документів TUWA

Тут лежать переклади документів з `docs/` українською: `terms.md`, `privacy.md`, `cookie.md`, `security.md`,
`dpa.md`, `transfer-assessment.md`, `refund.md`. `generate_pdf.js` збирає з них PDF і дані сторінок поруч (`terms.pdf`,
`terms.json`). Стандартні договірні положення (`scc-module-2.md`, `scc-module-3.md`) — офіційний текст ЄС, якого
українською немає: вони лишаються англійською.

## Правила

- **Оригінал — англійський текст.** Переклад оновлюється разом з ним; розділи, їх порядок і номери ті самі.
- **Якорі розділів — англійські:** кожен заголовок другого рівня закінчується `{#якір}` англійського розділу
  (`## 5. Обліковий запис і оплата {#account-billing}`). Скрипт не збирає переклад, у якому розділи або якорі
  відрізняються від оригіналу.
- **Дата:** рядок `Останнє оновлення: 23 жовтня 2026 р.`; скрипт змінює його, коли змінюється текст перекладу.
- **Посилання** ті самі, що в оригіналі (адреси сторінок без мовного префікса); назви документів у тексті посилань —
  українською.
- **Не перекладаються:** назви продуктів і пакетів (TUWA, Quasar Cloud, Quasar Community Edition, Pulsar, Nova UI Kit,
  SIWX), назви компаній і сервісів, ключі `localStorage` і cookies, коди, адреси, номери статей актів ЄС і їх офіційні
  назви англійською в дужках, якщо українського офіційного перекладу немає.
